# Faro Finanzas — Modo Hormiga
Aplicación web personal para organizar ingresos, gastos, deudas y presupuestos en pesos chilenos.

## Cómo activar su sitio
1. Abre **Settings → Pages** de este repositorio.
2. En **Build and deployment** selecciona **Deploy from a branch**.
3. Selecciona **main** y **/(root)**; guarda.
4. Cuando GitHub indique que el sitio está publicado, abre la URL que aparecerá en Pages usando Chrome.
5. En Chrome Android, menú **⋮ → Instalar aplicación** o **Agregar a pantalla principal**.

## Seguridad y privacidad
- El repositorio y el código de esta web son públicos. **Nunca publiques aquí tus datos financieros, respaldos, contraseñas, RUT, documentos, CSV bancarios ni claves de acceso.**
- Faro guarda datos **solo en este navegador y en este dispositivo**, cifrados con una contraseña elegida por ti. No se sincronizan entre aparatos.
- Respalda tu información regularmente desde la propia aplicación, y guarda la contraseña. Sin ella no se pueden recuperar respaldos cifrados.
- No introduzcas claves de BCI, Falabella o Mercado Pago: **Faro no se conecta a los bancos ni realiza transacciones.**
- Los cálculos de las deudas y recomendaciones son orientativos y no sustituyen los saldos del acreedor.
- No se ha realizado una auditoría de seguridad independiente.

**Importante:** No cambies de dominio u origen sin exportar antes un respaldo y confirmar la restauración en el nuevo sitio.

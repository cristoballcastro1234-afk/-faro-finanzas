# The Freedom Fight — Un día a la vez
Diario privado de 365 días, con diseño de espada y Biblia. Publicado como carpeta dentro del repositorio Faro, sin alterar la aplicación financiera.

## Instalación en Chrome Android
Abre https://cristoballcastro1234-afk.github.io/-faro-finanzas/the-freedom-fight/ en Chrome y entra a ⋮ → Instalar aplicación.

## Privacidad
Este repositorio almacena solo código público, NO tus notas. Las entradas se cifran y guardan localmente en el navegador con tu contraseña. Recuerda descargar respaldos cifrados y conservar tu contraseña. Nunca publiques aquí registros, copias de seguridad, contraseñas ni otros datos personales.

**Importante**: compartir un mismo dominio web con Faro no ofrece aislamiento completo entre ambas aplicaciones. Si buscas máxima separación, más adelante conviene publicar este diario en un repositorio y dominio propios.

No introduzcas aquí información que no deseas registrar. El diario no reemplaza la ayuda de profesionales de salud mental, líderes de confianza o personas que puedan acompañarte.
